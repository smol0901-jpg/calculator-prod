# 🍗 Ужарка PRO — карманный производственный калькулятор

Бесплатный веб-калькулятор для быстрого расчёта ужарки, выхода, потерь и необходимого входа сырья.

Создан для практической работы на производстве, проработок, расчётов потерь, контроля массы и быстрых записей в журнал.  
Работает прямо в браузере, не требует установки, регистрации, сервера, базы данных или оплаты.

---

## ✅ Что это такое

**Ужарка PRO** — это одностраничный HTML-калькулятор, который можно:

- открыть на телефоне;
- сохранить на главный экран как приложение;
- разместить бесплатно на GitHub Pages;
- использовать офлайн, если заранее открыть/сохранить страницу;
- применять для производственных расчётов и проработок.

Главная задача калькулятора — **дать результат за 10 секунд**.

---

## 🚀 Основные возможности

- расчёт выхода по входу и проценту ужарки;
- расчёт необходимого входа по нужному выходу;
- расчёт фактического процента ужарки по входу и выходу;
- быстрые пресеты: **1000 / 1070 / 1100 / свой**;
- запоминание последнего входа и процента;
- фиксация входа, чтобы случайно не изменить его во время проработки;
- журнал расчётов с датой и временем;
- автоматическая запись результатов;
- комментарий к расчёту: продукт, партия, смена, проработка;
- копирование результата в мессенджер, заметки или отчёт;
- экспорт журнала в CSV для Excel / Google Sheets;
- крупный результат для скриншота;
- режим печати / сохранения в PDF;
- светлая, тёмная и авто-тема;
- всё хранится локально на устройстве через localStorage.

## 📱 Как пользоваться

### Быстрый расчёт

1. Откройте калькулятор.
2. Нажмите нужный вход: **1000**, **1070**, **1100** или введите свой.
3. Укажите процент ужарки.
4. Сразу получите результат:
   - выход;
   - потерю;
   - коэффициент выхода;
   - дату и время.

---

## 🧮 Режимы работы

### 1. По проценту

Используется, когда известны:

- вход;
- процент ужарки.

Калькулятор посчитает:

- выход;
- потерю;
- коэффициент выхода.

Формула:

```text
Выход = Вход × (1 − Ужарка / 100)
```

---

### 2. Нужен вход

Используется, когда известны:

- нужный выход;
- процент ужарки.

Калькулятор посчитает, сколько входа нужно заложить.

Формула:

```text
Вход = Выход ÷ (1 − Ужарка / 100)
```

---

### 3. Факт %

Используется, когда известны:

- фактический вход;
- фактический выход.

Калькулятор посчитает фактический процент ужарки.

Формула:

```text
Ужарка % = (Вход − Выход) ÷ Вход × 100
```

## 💾 Установка на телефон

### Android / Chrome

1. Откройте страницу калькулятора.
2. Нажмите меню браузера.
3. Выберите **«Добавить на главный экран»**.

### iPhone / Safari

1. Откройте страницу в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите **«На экран Домой»**.

После этого калькулятор будет запускаться как обычное приложение с рабочего стола.
